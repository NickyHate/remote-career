# На земле

Гид по удалённой работе для бортпроводника с маленьким ребёнком и плавающим графиком.

Сайт собран под конкретную ситуацию: работа в «Северсталь Авиа», ребёнок 3,5 лет, ростер меняется каждую неделю. Нужна подработка уже сейчас — и понятная сфера, в которую можно уйти с линии позже.

## Что внутри

- Работы, которые можно делать кусками: карточки WB/Ozon, тексты, ассистент селлера, письменная поддержка, Canva, модерация
- Направления на 2–3 месяца: сорсинг, рекрутинг, спокойный SMM
- Три колеи «уйти с борта»: HR, клиентский опыт, менеджер маркетплейсов
- Честные вилки дохода, красные флаги и план на первый месяц
- Заготовка резюме, которую можно скопировать на hh.ru

Это не биржа вакансий в реальном времени. Ссылки ведут на актуальный поиск hh.ru / Kwork / Авито.

## Как запустить

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:43217](http://localhost:43217).

Сборка статического сайта:

```bash
npm run build
npm start
```

Папка `out/` — готовые HTML/CSS/JS. Их можно положить на любой бесплатный хостинг: GitHub Pages, Cloudflare Pages, Netlify.

## Как выложить на GitHub Pages (`*.github.io`)

Сайт уже собирается как статика, в репозитории есть workflow `.github/workflows/pages.yml`.

1. Создайте репозиторий на GitHub и запушьте этот проект в ветку `main`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. После пуша в `main` откроется адрес:
   - `https://<ник>.github.io/<имя-репозитория>/` — обычный проект
   - `https://<ник>.github.io/` — если репозиторий называется `<ник>.github.io`

Файлы из `_next` GitHub иначе прячет; скрипт сборки кладёт в `out/` пустой `.nojekyll`, чтобы стили не пропали.

## Кому это

Мамам и папам с сменным графиком в сервисе (авиация, поезда, медицина), которым нужна асинхронная удалёнка, а не колл-центр 5/2.
